Component

skeleton

Install

A placeholder component for all loading elements.

Basic

The same sections, in the same order, on every component page.

The Skeleton component is used to display a placeholder preview of content before the data gets loaded. This helps improve perceived performance and provides users with a visual indication that content is being loaded.

shadcn-dioxus add skeleton

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use dioxus::prelude::*;
use dioxus_primitives::activity::use_motion;
use dioxus_primitives::{dioxus_attributes::attributes, merge_attributes};

#[component]
pub fn Skeleton(#[props(extends=GlobalAttributes)] attributes: Vec<Attribute>) -> Element {
    let base = attributes!(div {
        class: "dx-skeleton", "data-dx-root": "",
    });
    // The pulse is paused while off-screen or in a hidden tab (`dx-components-theme.css`).
    let motion = use_motion();
    let merged = merge_attributes(vec![base, attributes, motion.attributes()]);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/skeleton/style.css") }
        div { ..merged }
    }
}

Skeleton {
    // Accepts all GlobalAttributes, commonly used with style for sizing
    style: "width: 15rem; height: 1rem;",
}

Skeleton Styled component

No props of its own. Plus the global attributes.

Component-Specific

What is particular to this component.

The pulse is an opacity animation that loops forever (2 s). It is paused whenever the skeleton is outside the viewport (plus a 200px pre-roll), inside a skipped content-visibility subtree or in a hidden tab, and it resumes where it stopped. Skeleton calls dioxus_primitives::activity::use_motion() and spreads motion.attributes() on its root; the theme's single [data-dx-motion="paused"] rule does the pausing.

To change or remove the pulse, override animation on .dx-skeleton. Under prefers-reduced-motion: reduce the pulse stops (animation: none, the box stays at full opacity), as in the shipped stylesheet; a copy that wants the pulse under reduced motion overrides that rule. See Motion for the tokens, reduced motion and the per-component table.

A component that composes this one retunes it by setting one of these custom properties on its own element, never by declaring the property on its own class: two stylesheets declaring one property on one element are decided by which sheet loads last, and that order differs from route to route. The component reads each variable with its own default, so a variable that is not set changes nothing. Custom properties inherit: set one on the exact element, not on an ancestor, or it reaches every nested instance too.

--dx-skeleton-radiusvar(--dx-radius-md)border-radius
