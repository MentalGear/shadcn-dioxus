The same sections, in the same order, on every component page.

The InputOtp component is a one-time-passcode entry control: a row of single-character boxes backed by one real, focusable <input>. Typing, Backspace/Delete, the arrow keys, and pasting a full code all work through that one real input; InputOtpSlot boxes are a purely visual, aria-hidden overlay that mirrors its value and caret position.

shadcn-dioxus add input_otp

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use dioxus::prelude::*;
use dioxus_primitives::dioxus_attributes::attributes;
use dioxus_primitives::input_otp::{
    self, InputOtpGroupProps, InputOtpProps, InputOtpSeparatorProps, InputOtpSlotProps,
};
use dioxus_primitives::merge_attributes;
pub use dioxus_primitives::input_otp::OtpPattern;

/// Composes [`input_otp::InputOtp`] (`dioxus_primitives`), attaching this
/// crate's `dx-input-otp-input` theming class to the primitive's real
/// (invisible) `<input>` -- see that primitive's module doc for why the
/// accessible surface lives on the real input rather than on a wrapper
/// `div`: it is simultaneously the interactive *and* the form-submittable
/// control, unlike `Checkbox`'s `<button>` + hidden `BubbleInput` split.
#[component]
pub fn InputOtp(props: InputOtpProps) -> Element {
    let base = attributes!(input { class: "dx-input-otp-input" });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/input_otp/style.css") }
        input_otp::InputOtp {
            attributes: merged,
            ..props
        }
    }
}

/// Lays out one cluster of [`InputOtpSlot`]s -- composes
/// [`input_otp::InputOtpGroup`].
#[component]
pub fn InputOtpGroup(props: InputOtpGroupProps) -> Element {
    let base = attributes!(div { class: "dx-input-otp-group", "data-dx-root": "" });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/input_otp/style.css") }
        input_otp::InputOtpGroup {
            attributes: merged,
            ..props
        }
    }
}

/// A single passcode digit box -- composes [`input_otp::InputOtpSlot`].
#[component]
pub fn InputOtpSlot(props: InputOtpSlotProps) -> Element {
    let base = attributes!(div { class: "dx-input-otp-slot" });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/input_otp/style.css") }
        input_otp::InputOtpSlot {
            attributes: merged,
            ..props
        }
    }
}

/// A visual divider between [`InputOtpGroup`]s -- composes
/// [`input_otp::InputOtpSeparator`]. `props.children` is forwarded only
/// when the caller actually supplied custom separator content, so an
/// omitted body still falls through to the primitive's own default ("•")
/// rather than this wrapper needing to duplicate it.
#[component]
pub fn InputOtpSeparator(props: InputOtpSeparatorProps) -> Element {
    let base = attributes!(div { class: "dx-input-otp-separator", "data-dx-root": "" });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/input_otp/style.css") }
        input_otp::InputOtpSeparator {
            attributes: merged,
            ..props
        }
    }
}

InputOtp {
    max_length: 6,
    aria_label: "One-time passcode",
    InputOtpGroup {
        InputOtpSlot { index: 0 }
        InputOtpSlot { index: 1 }
        InputOtpSlot { index: 2 }
    }
    InputOtpSeparator {}
    InputOtpGroup {
        InputOtpSlot { index: 3 }

}

InputOtpProps Primitive

The props for the InputOtp component.

PropTypeDefaultDescription
valueStringNone

The controlled value of the passcode (each character is one slot).

default_valueString""

The default value when uncontrolled.

on_value_changeCallback<String>no-op

Called whenever the value changes (typing, backspace/delete, paste).

on_completeCallback<String>no-op

Called once when the value's length reaches max_length (shadcn's onComplete) -- fires on the transition into "full", not on every keystroke made while already full.

max_lengthusize6

The number of character slots. Must be at least 1; values below 1 are clamped up to 1.

patternOtpPatternDefault::default()

Which characters are accepted. The <input>'s inputmode and pattern and the filter applied to typed/pasted text all derive from this one value (OtpPattern); default digits.

disabledboolfalse

Whether the whole control is disabled.

requiredboolfalse

Whether the passcode is required in a form.

nameString""

The name of the input, used in forms.

idStringNone

Optional id for the real input element -- also what a <label for> should point at, since the boxes are aria-hidden presentation.

childrenElementempty

The visual layer: InputOtpGroup/InputOtpSlot/ InputOtpSeparator, entirely aria-hidden.

Component-Specific

What is particular to this component.

pattern: OtpPattern is the one prop that decides what the code may contain, and the <input>'s inputmode, its pattern attribute and the filter applied to every typed or pasted value are all derived from it, so the keyboard and the accepted characters cannot disagree.

OtpPatternAcceptsKeyboardshadcn
Digits (default)0-9numericREGEXP_ONLY_DIGITS
AlphanumericA-Z a-z 0-9textREGEXP_ONLY_DIGITS_AND_CHARS
LettersA-Z a-ztextREGEXP_ONLY_CHARS
Custom { class, inputmode }the character-class body class, e.g. "A-Z0-9"inputmodecustom regex
InputOtp { max_length: 6, pattern: OtpPattern::Alphanumeric, aria_label: "Code", /* slots */ }
InputOtp { max_length: 4, pattern: OtpPattern::Custom { class: "0-9a-f".into(), inputmode: dioxus_primitives::input_otp::OtpInputMode::Text }, /* slots */ }

Rejected characters are removed as they arrive and the result is cut to max_length (a pasted A1-B2 into an alphanumeric code becomes A1B2; a pasted 123-456 into a six-slot code becomes 123456). The <input> carries no maxlength, because the browser would trim a paste to it before the filter runs. Raw inputmode or pattern attributes passed to InputOtp are overridden by the typed prop: it is the only way to set them. Letters keep their case.

The caret blinks (opacity, 1 s, forever) on the one focused slot only, i.e. while the user is typing into the field; it is visible by definition, so it is not gated (it is on check-motion-gating.sh's allowlist). Override animation on .dx-input-otp-slot[data-active="true"]::after to change or remove it; reduced motion swaps in --dx-motion-duration-reduced. See Motion for the tokens, reduced motion and the per-component table.
