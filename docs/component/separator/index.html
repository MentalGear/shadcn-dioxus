Basic

The same sections, in the same order, on every component page.

The Separator component is a simple horizontal or vertical line that can be used to visually separate content in your application.

shadcn-dioxus add separator

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use dioxus::prelude::*;
use dioxus_primitives::separator::{self, SeparatorProps};
use dioxus_primitives::{dioxus_attributes::attributes, merge_attributes};

#[component]
pub fn Separator(props: SeparatorProps) -> Element {
    let base = attributes!(div {
        class: "dx-separator", "data-dx-root": "",
    });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/separator/style.css") }
        separator::Separator {
            attributes: merged,
            ..props
        }
    }
}

// The Separator component can be oriented horizontally or vertically.
Separator {
    // The orientation of the separator line. true for horizontal, false for vertical.
    horizontal: true,
    // The decorative property controls if the separator is decorative and should not be visible to screen readers.
    decorative: false,
}

SeparatorProps Primitive

The props for the Separator component.

PropTypeDefaultDescription
horizontalbooltrue

Horizontal if true, vertical if false.

decorativeboolfalse

If the separator is decorative and should not be classified as a separator to the ARIA standard.

childrenElementempty

The children of the separator component.

Plus the global attributes.

Component-Specific

What is particular to this component.

A component that composes this one retunes it by setting one of these custom properties on its own element, never by declaring the property on its own class: two stylesheets declaring one property on one element are decided by which sheet loads last, and that order differs from route to route. The component reads each variable with its own default, so a variable that is not set changes nothing. Custom properties inherit: set one on the exact element, not on an ancestor, or it reaches every nested instance too.

VariableDefaultPropertyDescription
--dx-separator-backgroundvar(--dx-border)background-color

background-color of the rule. The size along the axis (width of a horizontal rule, height of a vertical one) is the orientation's, not a slot.

--dx-separator-margin0margin

margin of the rule.
