tabs

Install

A tabbed interface component.

Tab 1 Content

Basic

The same sections, in the same order, on every component page.

The Tabs component is used to create a tabbed interface, allowing users to switch between different views or sections of content.

shadcn-dioxus add tabs

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use dioxus::prelude::*;
use dioxus_primitives::tabs::{self, TabContentProps, TabListProps, TabTriggerProps};
use dioxus_primitives::{dioxus_attributes::attributes, merge_attributes};

/// The props for the [`Tabs`] component.
#[derive(Props, Clone, PartialEq)]
pub struct TabsProps {
    /// The class of the tabs component.
    #[props(default)]
    pub class: String,

    /// The controlled value of the active tab.
    pub value: ReadSignal<Option<String>>,

    /// The default active tab value when uncontrolled.
    #[props(default)]
    pub default_value: String,

    /// Callback fired when the active tab changes.
    #[props(default)]
    pub on_value_change: Callback<String>,

    /// Whether the tabs are disabled.
    #[props(default)]
    pub disabled: ReadSignal<bool>,

    /// Whether moving focus onto a tab also activates it (automatic activation). The default,
    /// `false`, is manual activation: arrow keys only move focus and `Enter`, `Space` or a click
    /// activates. See `dioxus_primitives::tabs::TabsProps::activate_on_focus`.
    #[props(default)]
    pub activate_on_focus: ReadSignal<bool>,

    /// Whether the tabs are horizontal (the default, shadcn's `orientation="horizontal"`).
    /// `false` lays the list out as a column beside the panels (shadcn's
    /// `orientation="vertical"`), moves focus with `ArrowUp`/`ArrowDown`, and sets
    /// `aria-orientation="vertical"` on the list.
    #[props(default = ReadSignal::new(Signal::new(true)))]
    pub horizontal: ReadSignal<bool>,

    /// Whether focus should loop around when reaching the end.
    #[props(default = ReadSignal::new(Signal::new(true)))]
    pub roving_loop: ReadSignal<bool>,

    /// Keep inactive panels mounted as `hidden="until-found"` so find-in-page and `#fragment`
    /// navigation can reach and open them. See `dioxus_primitives::tabs::TabsProps`.
    #[props(default)]
    pub hidden_until_found: ReadSignal<bool>,

    /// The variant of the tabs component.
    #[props(default)]
    pub variant: TabsVariant,

    /// The size of the tabs: the list's height follows the theme's shared control-height
    /// scale (`--dx-control-height-sm` / `-default` / `-lg`, 28 / 32 / 36px).
    #[props(default)]
    pub size: TabsSize,

    /// The text direction for `ArrowLeft`/`ArrowRight` roving focus.
    /// Defaults to the nearest [`dioxus_primitives::direction::DirectionProvider`], or
    /// LTR if there is none. See [`dioxus_primitives::direction::use_direction`].
    #[props(default)]
    pub dir: Option<dioxus_primitives::direction::Direction>,

    /// Additional attributes to apply to the tabs element.
    #[props(extends = GlobalAttributes)]
    pub attributes: Vec<Attribute>,

    /// The children of the tabs component.
    pub children: Element,
}

/// The variant of the tabs component.
#[derive(Clone, Copy, PartialEq, Default)]
pub enum TabsVariant {
    /// The default variant.
    #[default]
    Default,
    /// No pill: a transparent list, and the active tab carries a 2px bar (an underline
    /// when horizontal, a bar on the panel side when vertical): shadcn's `line` variant.
    Line,
    /// An alias of [`TabsVariant::Line`]: it renders identically
    /// (`data-variant="line"`).
    Ghost,
}

impl TabsVariant {
    /// Convert the variant to a string for use in class names
    fn to_class(self) -> &'static str {
        match self {
            TabsVariant::Default => "default",
            TabsVariant::Line | TabsVariant::Ghost => "line",
        }
    }
}

/// The size of the tabs component. `Default` is shadcn's 32px list and never changes.
#[derive(Clone, Copy, PartialEq, Default)]
pub enum TabsSize {
    /// A 28px list with `text-xs` triggers.
    Sm,
    /// The default 32px list.
    #[default]
    Default,
    /// A 36px list with roomier triggers.
    Lg,
}

impl TabsSize {
    /// Convert the size to a string for use in the `data-size` attribute
    fn to_class(self) -> &'static str {
        match self {
            TabsSize::Sm => "sm",
            TabsSize::Default => "default",
            TabsSize::Lg => "lg",
        }
    }
}

#[component]
pub fn Tabs(props: TabsProps) -> Element {
    let base = attributes!(div {
        class: format!("{} {}", props.class, "dx-tabs"),
        "data-variant": props.variant.to_class(),
        "data-size": props.size.to_class(),
    });
    let merged = merge_attributes(vec![base, props.attributes]);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tabs/style.css") }
        tabs::Tabs {
            dir: props.dir,
            value: props.value,
            default_value: props.default_value,
            on_value_change: props.on_value_change,
            disabled: props.disabled,
            activate_on_focus: props.activate_on_focus,
            horizontal: props.horizontal,
            roving_loop: props.roving_loop,
            hidden_until_found: props.hidden_until_found,
            attributes: merged,
            {props.children}
        }
    }
}

#[component]
pub fn TabList(props: TabListProps) -> Element {
    let base = attributes!(div {
        class: "dx-tabs-list"
    });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tabs/style.css") }
        tabs::TabList {
            attributes: merged,
            ..props
        }
    }
}

#[component]
pub fn TabTrigger(props: TabTriggerProps) -> Element {
    let base = attributes!(button {
        class: format!(
            "{} {}",
            "dx-tabs-trigger",
            props.class.clone().unwrap_or_default()
        )
    });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tabs/style.css") }
        tabs::TabTrigger {
            class: None,
            attributes: merged,
            ..props
        }
    }
}

#[component]
pub fn TabContent(props: TabContentProps) -> Element {
    let base = attributes!(div {
        class: format!(
            "{} {} {}",
            props.class.clone().unwrap_or_default(),
            "dx-tabs-content",
            "dx-tabs-content-themed"
        )
    });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tabs/style.css") }
        tabs::TabContent {
            class: None,
            attributes: merged,
            ..props
        }
    }
}

// The Tabs component wraps all tab triggers and contents. Arrow keys move through the triggers in document order.
Tabs {
    // The TabList component contains all the tab triggers
    TabList {
        // The TabTrigger component is used to create a clickable tab button that switches the active tab.
        TabTrigger {
            // The value of the tab trigger, which must be unique and is used to identify the active tab.
            value: "tab1",
            // The contents of the tab trigger button
            {children}
        }
    }
    // The TabContent component contains the content that is displayed when the corresponding tab is active.
    TabContent {
        // The value of the tab content, which must match the value of the corresponding TabTrigger to be displayed.
        value: "tab1",
        // The content of the tab, which is displayed when the tab is active.
        {children}
    }
}

disabledboolfalse

activate_on_focusboolfalse

Whether moving focus onto a tab also activates it (automatic activation): an arrow key, Home or End selects the tab it lands on, as Radix does by default.

Defaults to false, which is manual activation: focus only moves, and Enter, Space or a click activates the focused tab. Manual activation suits panels that are slow to render or that load data; automatic activation suits panels that appear instantly.

horizontalbooltrue

Whether the tabs are horizontal (the default). false is the vertical orientation: the list's TabTriggers move focus with ArrowUp/ArrowDown instead of ArrowLeft/ArrowRight, and TabList reports aria-orientation="vertical".

hidden_until_foundboolfalse

Keep every inactive TabContent mounted and mark it hidden="until-found", so the browser's find-in-page (Ctrl+F) and #fragment navigation can reach text inside inactive tabs. When they do, the browser reveals the panel and its tab becomes the active one (on_value_change is called with that tab's value).

Defaults to false, which unmounts inactive panels (they render as an empty hidden element), so it costs nothing until opted in. Opting in mounts, and on a server-rendered page hydrates, the content of every tab: effects, timers and charts in inactive tabs all run. The content of inactive tabs is also in the server-rendered HTML.

A stylesheet must not set display on an inactive panel: an author display: none defeats the browser rule that makes until-found content searchable.

Browser support: Chrome 102+, Safari 26.2+ (does not scroll to the match) and Firefox 139+ (148+ for a correct scroll target). Engines that do not know until-found treat it as plain hidden: inactive tabs stay unsearchable, as without the prop. Like hidden, inactive panels are not in the accessibility tree.

Revealing is not blocked by disabled. The browser un-hides the panel itself, so a controlled value that ignores on_value_change leaves the panel revealed while another tab reports active: a controlled parent should honor it.

Component-Specific

What is particular to this component.

Tabs takes variant: TabsVariant. Default is the muted pill with a raised active tab inside a bordered card. Line is shadcn's line variant: a transparent list with a 4px gap, no card around the panel, and the active tab carries a 2px bar that fades in (an underline when horizontal, a bar on the panel side when vertical; the docs site's DEMO/CODE tabs use it). Ghost is an alias of Line and renders identically (data-variant="line"). See the line variant.

(shadcn puts variant on TabsList; here it is on Tabs, because the panel's frame follows it too.)

Tabs takes horizontal: bool, true by default (shadcn's orientation="horizontal"). horizontal: false is shadcn's orientation="vertical": the list becomes a column beside the panels (flex-col, as tall as its triggers, triggers full width and start-aligned), and the root reports data-orientation="vertical". The list always carries aria-orientation (horizontal or vertical).

Keyboard follows WAI-ARIA: in a horizontal list ArrowLeft/ArrowRight move focus (swapped under RTL) and ArrowUp/ArrowDown do nothing; in a vertical list ArrowUp/ArrowDown move focus (never affected by direction) and ArrowLeft/ArrowRight do nothing. Home/End work in both, and focus wraps unless roving_loop is false. By default focus only moves and Enter or Space activates the focused tab (see "Activation" below). The vertical line bar sits on the end edge, the side that faces the panel, in RTL too. See the vertical and vertical_line variants.

Tabs { horizontal: false, variant: TabsVariant::Line, default_value: "a".to_string(), /* ... */ }

Behaviour change: horizontal used to default to false (vertical) in the primitive, although the styled component always rendered a row; it now defaults to true, so a Tabs that omitted it is a horizontal tab list with ArrowLeft/ArrowRight. Pass horizontal: false for the old keyboard.

By default activation is manual: the arrow keys, Home and End only move focus, and Enter, Space or a click activates the focused tab. That suits panels that are slow to render or load data. activate_on_focus: true is automatic activation: a tab that receives focus (from the keyboard, or from a click) is activated at once, so an arrow key walks through the panels. A disabled tab is skipped by focus and never activated. See the activate_on_focus variant.

Tabs { activate_on_focus: true, default_value: "a".to_string(), /* ... */ }

Tabs takes size: TabsSize (Sm, Default, Lg), emitted as data-size on the root. The list height follows the theme's shared control-height scale (--dx-control-height-sm / -default / -lg = 28 / 32 / 36px, the same ladder as Button, Input and Select), so a Sm tab list lines up with a Sm button. Default is shadcn's 32px list. Sm sets the triggers in text-xs with a 14px icon; Lg keeps text-sm and widens the trigger padding. Both variants (Default and Line) take every size, and a Tabs nested in another Tabs' panel keeps its own size. See the sizes variant.

Tabs { size: TabsSize::Sm, default_value: "a".to_string(), /* ... */ }

TabContent has no padding of its own (shadcn's Nova TabsContent is text-sm and nothing else; the 2rem padding of earlier releases was this library's). Put padding on the content, or on the panel with padding, or let a Card inside it bring its own. The default (bordered) variant still draws a 1px card-coloured frame around the panel, so text placed straight in it wants about var(--dx-space-4) of padding; the line variant has no frame.

Breaking change: a TabContent that relied on the 2rem padding now sits flush against its frame. Add padding: "var(--dx-space-8)" to restore the old look.

By default inactive panels are unmounted (an empty hidden element), so find-in-page (Ctrl+F) cannot see their text and a #fragment link cannot open them. Pass hidden_until_found: true on Tabs to keep every panel's content mounted and mark inactive panels hidden="until-found". The browser then searches them, and when a match is inside an inactive panel it reveals the panel and its tab becomes the active one: aria-selected and data-state follow, and on_value_change is called with that tab's value (a controlled value should follow it). See the until_found variant: try Ctrl+F for the word in its hint.

Tabs {
    default_value: "tab1".to_string(),
    hidden_until_found: true,
    // ...TabList and TabTrigger as above...
    TabContent { value: "tab2".to_string(), "Text that Ctrl+F can find while inactive" }
}

Cost: the content of every tab is mounted and, on a server-rendered page, hydrated, so effects, timers and charts inside inactive tabs all run, and all of it is in the server-rendered HTML. That is why it is opt-in; leave it off for heavy panels.

Browser support

Enginehidden="until-found"beforematch
Chrome / Edge 102+YesYes
Firefox148+ (139 to 147: reveals, may scroll to the wrong place)139+
Safari26.2+, partial: reveals the content but does not scroll to the match26.2+
Older enginesTreated as plain hidden: the content stays closed and unsearchable, exactly as without the propn/a

Nothing breaks where it is unsupported: the content is simply not found by find-in-page, as it is by default.

Accessibility

Inactive until-found panels are hidden from the accessibility tree exactly like hidden: screen readers only reach the active panel, as with plain tabs. Find-in-page is the one way to reach an inactive panel without selecting its tab; it is exposed as soon as it activates.

Styling

TabContent carries hidden when inactive (hidden="until-found" with the opt-in). A stylesheet must not set display: none on an until-found panel: that overrides the browser rule that keeps its text searchable. The shipped stylesheet skips [hidden="until-found"] and takes such a panel out of flow at zero size, so the inactive panels add no empty cards or gaps.

Trigger colours and the line variant's bar change over --dx-motion-duration-base with --dx-motion-ease-standard; the panels switch instantly. Retune with those tokens. Reduced motion swaps in --dx-motion-duration-reduced. Nothing loops. See Motion for the tokens, reduced motion and the per-component table.

Tabs accepts a dir: Option<Direction> prop (defaulting to the nearest DirectionProvider, or LTR). Under RTL, TabTrigger's ArrowLeft/ArrowRight roving focus swaps: ArrowLeft moves to the next tab, ArrowRight to the previous one (matching Radix's shared RovingFocusGroup behavior). See the rtl variant.
