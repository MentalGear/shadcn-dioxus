radio group

Install

A group of radio buttons for selecting one option from a set.

shadcn-dioxus add radio_group

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use dioxus::prelude::*;
use dioxus_primitives::dioxus_attributes::attributes;
use dioxus_primitives::merge_attributes;
use dioxus_primitives::radio_group::{self, RadioGroupProps, RadioItemProps};

// dev-docs/backlog.md row 32: see checkbox/component.rs's
// header comment for the full delivery-mechanism rationale (asset!() +
// document::Link, embedded in both exported entry points so a
// `shadcn-dioxus add radio_group`-copied component needs no extra wiring).
//
// Its item class is `dx-radio-group-item`, not a bare `dx-radio-item`:
// without a hash suffix, a plain `dx-radio-item` isn't provably this
// component's own -- see `scripts/check-dx-class-prefix.sh`.
#[component]
pub fn RadioGroup(props: RadioGroupProps) -> Element {
    let base = attributes!(div { class: "dx-radio-group", "data-dx-root": "" });
    let merged = merge_attributes(vec![base, props.attributes]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/radio_group/style.css") }
        radio_group::RadioGroup {
            dir: props.dir,
            value: props.value,
            default_value: props.default_value,
            on_value_change: props.on_value_change,
            disabled: props.disabled,
            required: props.required,
            name: props.name,
            form: props.form,
            horizontal: props.horizontal,
            roving_loop: props.roving_loop,
            attributes: merged,
            {props.children}
        }
    }
}

#[component]
pub fn RadioItem(props: RadioItemProps) -> Element {
    // This wrapper forwards `props.id` to the underlying primitive and
    // merges `props.class` instead of clobbering it:
    // `preview/src/components/form/component.rs`'s fixture relies on
    // stable ids (`#plan-lib-pro` etc.) for both its `<label for>`
    // associations and this repo's Playwright oracles to find each radio
    // button. Merges `class` the same way `../popover/component.rs`'s
    // `PopoverContent` does, for the same reason: a caller's own class
    // should extend, not replace, this theme's.
    let class = if let Some(class) = props.class {
        format!("{} {}", "dx-radio-group-item", class)
    } else {
        "dx-radio-group-item".to_string()
    };

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/radio_group/style.css") }
        radio_group::RadioItem {
            id: props.id,
            class,
            value: props.value,
            index: props.index,
            disabled: props.disabled,
            attributes: props.attributes,
            {props.children}
        }
    }
}

The RadioGroup component is used to create a group of radio buttons that allows the user to select one option from a set.

// The RadioGroup component wraps all radio items in the group.
RadioGroup {
    // The value property represents the currently selected radio button in the group.
    value: "option1",
    on_value_change: |value: String| {
        // This callback is triggered when the selected radio button changes.
        // The value parameter contains the value of the newly selected radio button.
    },
    // The RadioItem component represents each individual radio button in the group.
    RadioItem {
        // The value of the radio button, which is used to identify the selected option and will be passed to the on_value_change callback when selected.
        value: "option1",
        // The contents of the radio item button
        {children}
    }
}

RadioGroup accepts a dir: Option<Direction> prop. When horizontal: true, RadioItem's ArrowLeft/ArrowRight roving focus swaps under RTL the same way Tabs' does. See the rtl variant.

Pass form: "form-id".to_string() (the HTML form attribute) and the control's hidden mirror input belongs to that <form> even when it is rendered elsewhere in the page: it submits with it and the form's reset restores it. Leave it out and the nearest ancestor <form> owns it.

RadioGroupProps Primitive

The props for the RadioGroup component.

PropTypeDefaultDescription
valueStringNone

The controlled value of the selected radio item.

default_valueString""

The default selected value when uncontrolled.

on_value_changeCallback<String>no-op

Callback fired when the selected value changes.

disabledboolfalse

Whether the radio group is disabled.

requiredboolfalse

Whether the radio group is required in a form.

nameString""

The name attribute for form submission.

formStringNone

The id of a <form> the hidden input belongs to (the HTML form attribute), so a control rendered outside its <form> still submits and resets with it. None leaves the input's owner to the DOM ancestor.

horizontalboolfalse

Whether the radio group is horizontal.

dirDirectionNone

The text direction for ArrowLeft/ArrowRight roving focus. Defaults to the nearest crate::direction::DirectionProvider, or LTR if there is none. See crate::direction::use_direction.

roving_loopbooltrue

Whether focus should loop around when reaching the end.

childrenElementempty

The children of the radio group component.

Plus the global attributes.

RadioItemProps Primitive

The props for the RadioItem component

PropTypeDefaultDescription
valueStringrequired

The value of the radio item. This will be passed to RadioGroupProps::on_value_change when selected.

indexusizeNone

The item's place in keyboard order within the RadioGroup. Leave it unset: items are ordered as they are created, which is tree order. Set it on every item only when an item is inserted between items that are already mounted, or a keyed list reorders them.

disabledboolfalse

Whether the radio item is disabled.

idStringNone

Optional ID for the radio item element.

classStringNone

Optional class for the radio item element.

childrenElementempty

The children of the radio item component.

Plus the global attributes.
