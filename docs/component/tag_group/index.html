A Tag Group is a focusable group of tags (labels, categories, filters and similar items) with keyboard navigation, optional selection and removal.

shadcn-dioxus add tag_group

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use dioxus::prelude::*;
use crate::components::icons::X;
use dioxus_primitives::dioxus_attributes::attributes;
use dioxus_primitives::merge_attributes;
use dioxus_primitives::tag_group::{
    self, TagGroupEmptyProps, TagGroupLabelProps, TagGroupMultiProps, TagGroupProps, TagListProps,
};

// dev-docs/backlog.md row 32: see checkbox/component.rs's
// header comment for the full delivery-mechanism rationale (asset!() +
// document::Link, embedded in every exported entry point of this file so a
// `shadcn-dioxus add tag_group`-copied component needs no extra wiring).
//
// Every class lives under the full `dx-tag-group-` namespace
// (`dx-tag-group-tag`, `dx-tag-group-list`, `dx-tag-group-remove-button`), in
// both this file and `style.css`. A short `.dx-remove-button` would collide
// with `drag_and_drop_list`'s differently-sized one (26x26px +
// `margin-left: 10px` vs this one's unsized, `margin-left: 0.25rem`) and
// silently restyle whichever sheet lost the CSS load order (backlog row 32);
// `dx-tag` and `dx-tag-list` would be out of namespace even without an active
// collision -- see `scripts/check-dx-class-prefix.sh`.
#[component]
pub fn TagGroup(props: TagGroupProps<String>) -> Element {
    let base = attributes!(div { class: "dx-tag-group", "data-dx-root": "" });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tag_group/style.css") }
        tag_group::TagGroup {
            attributes: merged,
            ..props
        }
    }
}

#[derive(Props, Clone, PartialEq)]
pub struct TagProps {
    /// The tag's value, reported when it is selected or removed.
    pub value: ReadSignal<String>,
    /// Plain text used for typeahead when the tag's content is not text.
    #[props(default)]
    pub text_value: ReadSignal<Option<String>>,
    /// The tag's position in the list; keeps keyboard order stable.
    pub index: ReadSignal<usize>,
    /// The `id` of the tag element.
    #[props(default)]
    pub id: ReadSignal<Option<String>>,
    /// Whether the tag is disabled.
    #[props(default)]
    pub disabled: ReadSignal<bool>,
    #[props(extends = GlobalAttributes)]
    pub attributes: Vec<Attribute>,
    /// The tag's content.
    pub children: Element,
}

#[component]
pub fn Tag(props: TagProps) -> Element {
    let base = attributes!(div { class: "dx-tag-group-tag" });
    let merged = merge_attributes(vec![base, props.attributes]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tag_group/style.css") }
        tag_group::TagOption::<String> {
            value: props.value,
            text_value: props.text_value,
            disabled: props.disabled,
            id: props.id,
            index: props.index,
            attributes: merged,
            {props.children}
        }
    }
}

#[component]
pub fn RemoveButton(
    #[props(extends = GlobalAttributes)] attributes: Vec<Attribute>,
    /// Extra content inside the button, before the remove icon. Usually left empty.
    children: Element,
) -> Element {
    let base = attributes!(button { class: "dx-tag-group-remove-button" });
    let merged = merge_attributes(vec![base, attributes]);
    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/tag_group/style.css") }
        tag_group::TagRemoveButton {
            attributes: merged,
            {children}
            X { size: "12px" }
        }
    }
}

Single selection with TagGroup:

let mut value = use_signal(|| None::<String>);

TagGroup {
    value: Some(value.into()),
    on_value_change: move |next| value.set(next),
    on_remove: move |removed: Vec<String>| { /* drop them from your list */ },
    TagGroupLabel { "Labels" }
    TagList {
        TagGroupEmpty { "No tags" }
        Tag { index: 0usize, value: "bug", "bug" RemoveButton {} }
        Tag { index: 1usize, value: "feature", disabled: true, "feature" }
    }
}

Component-Specific

What is particular to this component.

A tag with a RemoveButton child is removable, by the button or by Delete/Backspace on the focused tag (which removes every selected removable tag when the focused one is selected). The tag hides itself and on_remove reports the removed values, in list order, so an app that owns the list drops them there (the multi demo). Removing a selected tag also updates the selection through on_value_change/on_values_change.

Some props here come in controlled pairs. Controlled and uncontrolled state says how they work, and what freezes a component.

  • TagGroupProps: value with on_value_change; uncontrolled start value default_value.
  • TagGroupMultiProps: values with on_values_change; uncontrolled start value default_values.
