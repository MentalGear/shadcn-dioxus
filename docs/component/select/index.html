select

A select dropdown component with typeahead support.

Basic

The same sections, in the same order, on every component page.

The Select component is used to create a dropdown menu that allows users to select one or more options from the select groups.

shadcn-dioxus add select

Also adds the components and crates this one needs. First time in this app? Set up the CLI and your app first.

Copy the component source and CSS into your app. Import the shared theme CSS once near your app root.

use crate::components::icons::{Check, ChevronDown, ChevronUp};
use dioxus_primitives::select::{self, SelectGroupLabelProps, SelectOptionProps};
use dioxus_primitives::{dioxus_attributes::attributes, merge_attributes};

pub use dioxus_primitives::select::{SelectGroup, SelectPosition};

// dev-docs/backlog.md row 32: see checkbox/component.rs's
// header comment for the full delivery-mechanism rationale (asset!() +
// document::Link, embedded in the wrapper so a `shadcn-dioxus add
// select`-copied component needs no extra wiring). This file has TWO
// independent entry components (`Select` and `SelectMulti` -- callers use
// exactly one, never both), so the stylesheet Link is placed in both of
// them rather than only the first (a single injection would have to fire from
// whichever of the two happens to render first). `SelectGroupLabel`/`SelectOption` are
// always composed as children of one of those two (never standalone, per
// this crate's own API), so they don't need their own copy --
// `document::Link`'s `(href, rel)` dedup makes it harmless either way if a
// future edit adds one there too.

/// The size of a [`Select`] / [`SelectMulti`] trigger: shadcn's `size="sm" | "default"`
/// (Nova's `data-[size=default]:h-8 data-[size=sm]:h-7`), read from the theme's
/// control-height ladder.
#[derive(Copy, Clone, PartialEq, Default)]
#[non_exhaustive]
pub enum SelectSize {
    #[default]
    Default,
    Sm,
}

impl SelectSize {
    pub fn class(&self) -> &'static str {
        match self {
            SelectSize::Default => "default",
            SelectSize::Sm => "sm",
        }
    }
}

/// Props for the themed [`Select`]. Deliberately its own struct rather than
/// a reuse of `dioxus_primitives::select::SelectProps` (as the other
/// wrappers in this file still do for their simpler primitives): callers
/// that need to customize the trigger's accessible name/content or the
/// option list's accessible name (e.g. the dashboard email client's tag
/// filter, or the form fixture's required-field labels) have nowhere to
/// pass that through `SelectTrigger`/`SelectList`'s own props once this
/// wrapper hard-codes them internally, so those become explicit fields here
/// instead.
#[derive(Props, Clone, PartialEq)]
pub struct SelectProps<T: Clone + PartialEq + 'static = String> {
    /// The controlled value of the select. If supplied, the select is
    /// controlled and the signal's `None` value means no option is
    /// selected.
    #[props(default)]
    pub value: Option<ReadSignal<Option<T>>>,

    /// The initial value of the select when uncontrolled.
    #[props(default)]
    pub default_value: Option<T>,

    /// A selected value's display text, shown in the trigger. Required: it is read at render time, so a
    /// preselected value has its text in the server-rendered HTML (the option registry is filled by a
    /// client-only effect and can never supply it).
    pub item_to_label: Callback<T, String>,

    /// Callback fired when the selected value changes.
    #[props(default)]
    pub on_value_change: Callback<Option<T>>,

    /// Whether the select is disabled.
    #[props(default)]
    pub disabled: ReadSignal<bool>,

    /// The controlled open state of the select popup.
    #[props(default)]
    pub open: ReadSignal<Option<bool>>,

    /// The initial open state when uncontrolled.
    #[props(default)]
    pub default_open: ReadSignal<bool>,

    /// Callback fired when the popup open state changes.
    #[props(default)]
    pub on_open_change: Callback<bool>,

    /// Name of the select for form submission.
    #[props(default)]
    pub name: ReadSignal<String>,

    /// Whether a selection is required for form submission.
    #[props(default)]
    pub required: ReadSignal<bool>,

    /// Whether focus should loop around when reaching the end. Off by default, as in shadcn.
    #[props(default = ReadSignal::new(Signal::new(false)))]
    pub roving_loop: ReadSignal<bool>,

    /// Timeout in milliseconds before clearing the typeahead buffer.
    #[props(default = ReadSignal::new(Signal::new(Duration::from_millis(1000))))]
    pub typeahead_timeout: ReadSignal<Duration>,

    /// Where the list is placed: with the selected option over the trigger (`ItemAligned`, the
    /// default, shadcn's `position="item-aligned"`) or below the trigger (`Popper`). A touch open
    /// is always placed as popper.
    #[props(default)]
    pub position: ReadSignal<select::SelectPosition>,

    /// ARIA label applied to the trigger button. Ignored when `trigger` is
    /// supplied -- the caller's custom trigger content is then responsible
    /// for its own accessible name.
    #[props(default)]
    pub trigger_aria_label: Option<String>,

    /// ARIA label applied to the option list.
    #[props(default)]
    pub list_aria_label: Option<String>,

    /// Placeholder text shown by the default trigger content
    /// (`SelectValue`) while nothing is selected. Ignored when `trigger` is
    /// supplied.
    #[props(default)]
    pub placeholder: Option<String>,

    /// Extra class appended alongside `"dx-select-trigger"`.
    #[props(default)]
    pub trigger_class: Option<String>,

    /// Trigger size, `Default` (32px) or `Sm` (28px): `data-size` on the trigger.
    #[props(default)]
    pub size: SelectSize,

    /// Extra class appended alongside `"dx-select-list"`.
    #[props(default)]
    pub list_class: Option<String>,

    /// Custom content for the trigger button, replacing the default
    /// `SelectValue`. The themed chevron icon is always appended after it.
    #[props(default)]
    pub trigger: Option<Element>,

    /// The text direction, emitted on the trigger and listbox content.
    /// Defaults to the nearest [`dioxus_primitives::direction::DirectionProvider`], or
    /// LTR if there is none.
    #[props(default)]
    pub dir: Option<dioxus_primitives::direction::Direction>,

    /// Additional attributes for the select's root element.
    #[props(extends = GlobalAttributes)]
    pub attributes: Vec<Attribute>,

    /// The option/group children rendered inside the themed option list.
    pub children: Element,
}

    #[props(default)]

    /// The controlled open state of the select popup.
    #[props(default)]
    pub open: ReadSignal<Option<bool>>,

    /// The initial open state when uncontrolled.
    #[props(default)]
    pub default_open: ReadSignal<bool>,

    /// Callback fired when the popup open state changes.
    #[props(default)]
    pub on_open_change: Callback<bool>,

    /// Name of the select for form submission.
    #[props(default)]
    pub name: ReadSignal<String>,

    /// Whether focus should loop around when reaching the end. Off by default, as in shadcn.
    #[props(default = ReadSignal::new(Signal::new(false)))]
    pub roving_loop: ReadSignal<bool>,

    #[props(default = ReadSignal::new(Signal::new(Duration::from_millis(1000))))]
    pub typeahead_timeout: ReadSignal<Duration>,

    /// Where the list is placed: with the selected option over the trigger (`ItemAligned`, the
    /// default, shadcn's `position="item-aligned"`) or below the trigger (`Popper`). A touch open
    /// is always placed as popper.
    #[props(default)]
    pub position: ReadSignal<select::SelectPosition>,

    /// ARIA label applied to the trigger button. Ignored when `trigger` is
    /// supplied.
    #[props(default)]
    pub trigger_aria_label: Option<String>,

    /// ARIA label applied to the option list.
    #[props(default)]
    pub list_aria_label: Option<String>,

    /// Placeholder text shown by the default trigger content
    /// (`SelectValue`) while nothing is selected. Ignored when `trigger` is
    /// supplied.
    #[props(default)]
    pub placeholder: Option<String>,

    /// Extra class appended alongside `"dx-select-trigger"`.
    #[props(default)]
    pub trigger_class: Option<String>,

    /// Trigger size, `Default` (32px) or `Sm` (28px): `data-size` on the trigger.
    #[props(default)]
    pub size: SelectSize,

    /// Extra class appended alongside `"dx-select-list"`.
    #[props(default)]
    pub list_class: Option<String>,

    /// Custom content for the trigger button, replacing the default
    /// `SelectValue`. The themed chevron icon is always appended after it.
    #[props(default)]

    #[props(default)]

    #[props(extends = GlobalAttributes)]
    pub attributes: Vec<Attribute>,

    /// The option/group children rendered inside the themed option list.
    pub children: Element,

/// Merges `extra` alongside `base`, `base`-first, for the handful of themed
/// sub-elements (trigger, list) that take an optional caller-supplied extra
/// class on top of their own fixed theme class.
fn with_extra_class(base: impl std::fmt::Display, extra: &Option<String>) -> String {
    match extra {
        Some(extra) if !extra.is_empty() => format!("{base} {extra}"),
        _ => base.to_string(),
    }
}

#[component]
pub fn Select<T: Clone + PartialEq + 'static>(props: SelectProps<T>) -> Element {
    let base = attributes!(div { class: "dx-select", "data-dx-root": "" });
    let merged = merge_attributes(vec![base, props.attributes]);
    let trigger_class = with_extra_class("dx-select-trigger", &props.trigger_class);
    let list_class = with_extra_class("dx-select-list", &props.list_class);

    rsx! {
        document::Link { rel: "stylesheet", href: asset!("/src/components/select/style.css") }
        select::Select {
            dir: props.dir,
            value: props.value,
            default_value: props.default_value,
            item_to_label: props.item_to_label,
            on_value_change: props.on_value_change,
            disabled: props.disabled,
            open: props.open,
            default_open: props.default_open,
            on_open_change: props.on_open_change,
            name: props.name,
            required: props.required,
            roving_loop: props.roving_loop,
            typeahead_timeout: props.typeahead_timeout,
            position: props.position,
            attributes: merged,
            select::SelectTrigger {
                class: trigger_class,
                "data-size": props.size.class(),
                aria_label: props.trigger_aria_label.clone(),
                if let Some(trigger) = &props.trigger {
                    {trigger.clone()}
                } else if let Some(placeholder) = props.placeholder.clone() {
                    select::SelectValue { placeholder }
                } else {
                    // No caller-supplied placeholder: leave `SelectValue`'s
                    // own field unset so its primitive default ("Select an
                    // option") applies, rather than overriding it with an
                    // empty string.
                    select::SelectValue {}
                }
                ChevronDown {
                    class: "dx-select-expand-icon",
                    size: "16px",
                    stroke: "var(--dx-muted-foreground)",
                }
            }
            select::SelectList {
                class: list_class,
                "data-dx-surface": "floating",
                aria_label: props.list_aria_label.clone(),
                select::SelectScrollUpButton { class: "dx-select-scroll-button", ChevronUp { size: "16px" } }
                {props.children}
                select::SelectScrollDownButton { class: "dx-select-scroll-button", ChevronDown { size: "16px" } }
            }
        }
    }
}

#[component]

#[component]
pub fn SelectOption<T: Clone + PartialEq + 'static>(props: SelectOptionProps<T>) -> Element {
    let base = attributes!(div { class: "dx-select-option" });
    let merged = merge_attributes(vec![base, props.attributes.clone()]);

    let children = props.children.clone();
    rsx! {
        select::SelectOption::<T> {
            attributes: merged,
            ..props,
            {children}
            select::SelectItemIndicator {
                Check {
                    class: "dx-select-option-indicator",
                    size: "1rem",
                    stroke: "var(--dx-muted-foreground)",
                }
            }
        }
    }
}

    SelectGroup {
        SelectGroupLabel { "Group A" }

SelectListRendered Primitive

Browser arm: promote the listbox to the top layer via popover="manual" so it escapes clipping/transformed ancestors, the same construction as Tooltip/HoverCard/Combobox (dev-docs/plan.md Phase 4.4). The placement is the engine's anchored popper, or the item-aligned script (use_item_aligned), per SelectContext::placement.

manual, not auto

The trigger opens the list on pointerdown for a mouse, so the list becomes :popover-open between a gesture's pointerdown and pointerup. An auto popover opened there is hidden by that same gesture's pointerup (the opening-gesture contract in crate::top_layer::PopoverKind::Auto; with the popper placement the release lands outside the list). A manual popover is never light-dismissed, so this component owns every dismissal:

  • Escape, an outside press and focus leaving: the dismiss core (crate::dismiss::Policy::ESCAPE_PRESS_AND_FOCUS) on the list. Escape closes the list while focus is on the list or an option and cancels the key, so an enclosing dialog stays open (on the trigger, SelectTrigger's own Escape arm takes the key, also before this layer has registered on the page); a mouse press outside dismisses at once, a touch or pen press as a tap, so a page scroll that starts outside leaves the list open. This listbox's own onblur and an individual option's (option.rs) also close it when focus leaves the whole widget. An outside press or focus leaving lands on interacted_outside = true, open = false, which is idempotent when more than one fires.
  • Animation: does not use crate::top_layer::use_popover_sync bound to the raw open signal, unlike the other anchored consumers -- see crate::top_layer::use_popover_shown_while_mounted's doc for the animate-out race that binding would otherwise cause with crate::use_animated_open (SelectList, above), and why this mount/unmount-scoped variant avoids it.

Page scroll is not locked while the list is open and the panel stays attached to the trigger as the page scrolls (row 477's placement); the list scrolls inside its own overflow (row 478).

Component-Specific

What is particular to this component.

item_to_label: Callback<T, String> is required on Select and SelectMulti (like Base UI's itemToStringLabel and ComboboxMulti's). SelectValue and the trigger's fallback accessible name read it at render time, never the option registry: options register in a client-only effect and come after the trigger in tree order, so a registry-derived label is empty in the server HTML (a preselected Select would show its placeholder until hydration). A required prop, not a T: Display default, because select values are often &str, numbers or enums with no Display, and a default that falls back to the registry would reintroduce the empty first paint. SelectMulti joins its values' labels with a comma. A label that differs from an option's own text is fine; keep them equal so the trigger reads like the row that was picked.

The list scrolls inside the popup (max-height: min(18rem, var(--dx-available-height))). Select and SelectMulti put a SelectScrollUpButton first and a SelectScrollDownButton last in the list (shadcn's SelectScrollUpButton / SelectScrollDownButton); a primitive-level caller places them the same way. Each is sticky at its edge, out of flow (showing one never moves an option), hidden from assistive technology, and visible only while the list can scroll that way (data-visible): a passive scroll listener through js_listener.rs reports the position. Hovering one with a mouse scrolls the list (6 px per 16 ms tick) through use_interval_while, gated by use_motion, so a hidden tab or a skipped card pauses it; leaving, or reaching the end, stops it. See the scroll variant.

position is SelectPosition::ItemAligned by default, as in both shadcn variants (base-nova alignItemWithTrigger, new-york-v4 position="item-aligned"): the list opens over the trigger with the selected option on the trigger's line, moved and then scrolled to stay inside the viewport. With no selected option there is nothing to align: the whole list opens below the trigger and flips above it when it does not fit there and the room above is larger, capped to that side's room (data-side on the list). SelectPosition::Popper opens the list below the trigger and flips it above when there is no room. A Select opened by touch is always placed as popper, as Base UI does: the finger would cover the option that sits over the trigger. See the aligned and popper variants.

The panel is placed in document coordinates, so it stays attached to the trigger while the page scrolls. A Select does not lock page scroll; the page scrolls while the list is open.

A mouse opens the list on press (pointerdown), as both upstreams do; releasing the button over an option does not pick it (an option is picked by a press that starts on it). A touch or pen opens it on the tap (click), so a scroll that starts on the trigger leaves it closed. Enter, Space, ArrowDown and ArrowUp open it from the keyboard.

ArrowUp, ArrowDown, Home and End move the highlight and stop at the first and last option: neither Radix nor Base UI wraps. roving_loop: true makes the arrow keys wrap.

A press or tap opens a single Select on its selected option, focused and scrolled into view, the same as a keyboard open (Base UI opens on the selected index for every modality). With nothing selected, or in SelectMulti, a pointer open leaves focus on the listbox and ArrowDown reaches the first option. A DropdownMenu / ContextMenu does the opposite on purpose: a keyboard open focuses the first item, a pointer open highlights none.

size: SelectSize::Sm makes the trigger 28px tall (--dx-control-height-sm) instead of the default 32px (--dx-control-height-default), shadcn's size="sm" | "default" on SelectTrigger. It sets data-size on the trigger of both Select and SelectMulti. See the sizes variant.

With a name, both selects take part in their enclosing <form> through a hidden native mirror. Select renders a <select> and submits one name=value entry for its value (none while nothing is selected); required blocks the submit until a value is chosen. SelectMulti renders a <select multiple> and submits one name=value entry per selected value, in option order, and nothing for an empty selection. The submitted value is the option's text_value (for a String value, the value itself when unset), never its label. A form reset restores default_value / default_values. SelectMulti has no required.

Some props here come in controlled pairs. Controlled and uncontrolled state says how they work, and what freezes a component.

  • SelectProps: value with on_value_change; uncontrolled start value default_value.
  • SelectProps: open with on_open_change; uncontrolled start value default_open.
  • SelectMultiProps: values with on_values_change; uncontrolled start value default_values.
  • SelectMultiProps: open with on_open_change; uncontrolled start value default_open.

The list fades and scales in and out over --dx-floating-duration (the shared dx-pop-in/dx-pop-out: opacity, scale from 0.95, a 2px translate); option highlights use --dx-motion-duration-fast. Retune with those tokens. Reduced motion swaps in --dx-motion-duration-reduced. Nothing loops. See Motion for the tokens, reduced motion and the per-component table.

Select/SelectMulti accept a dir: Option<Direction> prop, emitted as dir/data-direction on the trigger and the listbox. The trigger/listbox's own keyboard navigation is vertical-only (ArrowUp/ArrowDown/Home/End), so there is no arrow-key behavior to flip. See the rtl variant.

A component that composes this one retunes it by setting one of these custom properties on its own element, never by declaring the property on its own class: two stylesheets declaring one property on one element are decided by which sheet loads last, and that order differs from route to route. The component reads each variable with its own default, so a variable that is not set changes nothing. Custom properties inherit: set one on the exact element, not on an ancestor, or it reaches every nested instance too.
