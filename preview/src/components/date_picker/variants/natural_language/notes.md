A plain `Calendar` in a `Popover` (no `confirm`); closes on select and writes the field. Mirrors shadcn's `date-picker-natural-language`, "Natural Language Picker": a text field that understands phrases. The label is "Schedule Date", the placeholder "Tomorrow or next week", it starts as "In 2 days", and the line below reads "Your post will be published on **October 16, 2026**." Every keystroke is parsed; text that does not parse keeps the previous date. ArrowDown in the field opens the calendar, whose button sits inside the field (an icon button labelled "Select date", popover end-aligned); picking a day writes it into the field and closes. shadcn parses with `chrono-node`; this demo has a small hand-written parser instead (today, tomorrow, yesterday, `in N days/weeks/months`, `N days ago`, `next week/month`, weekday names, `2026-10-20`, `October 20, 2026`, `20 Oct`). It is demo code, not part of the component.
