`use_message_scroller_visibility()` returns the reader's position as a signal: `current_anchor_id` (the last turn anchor, here each user message, whose top has reached the reading line) and `visible_message_ids` (the rows in view, in document order). The header reads it to show which turn is current and how many rows are in view. The controller observes rows only while a subscriber is mounted, and reports only when the state changes, never per scroll event. The footer's two buttons call `scroll_to_message` with `ScrollBehavior::Instant`, one with the provider's margin and one with `scroll_margin: Some(24.0)` for that call only.
