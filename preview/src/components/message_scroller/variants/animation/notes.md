User rows enter with one of the theme's shared keyframes (`dx-fade-in`, `dx-pop-in`, `dx-drop-in`), chosen in a `Select`. The preset in force when a row is sent is stored with that row, so changing it later never replays the rows already on screen. These keyframes animate only `opacity`, `scale` and `translate`, so a row's measured height never changes while it plays and anchoring is unaffected.
