User rows enter with one of six entrance keyframes, chosen in a `Select`: the theme's shared `dx-fade-in`, `dx-pop-in` and `dx-drop-in`, and `dx-effects.css`'s `dx-enter-spring-bounce` (a `linear()` spring easing), `dx-enter-blur-fade` and `dx-enter-slide-side`. The demo shows only the sent bubbles, so the entrance is the one thing moving. The preset in force when a row is sent is stored with that row, so changing it later never replays the rows already on screen. The keyframes animate only `opacity`, `scale`, `translate` and `filter`, so a row's measured height never changes while it plays and anchoring is unaffected; reduced motion shows the row at once.
