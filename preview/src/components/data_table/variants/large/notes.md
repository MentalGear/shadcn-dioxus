50,000 orders in `layout: DataTableLayout::Grid`: the same `Column<T>` definitions and `use_data_table` state as the paged table, drawn through a `VirtualGrid` that scrolls instead of paging. Sort from the headers, filter by customer or status, and select rows with the checkboxes; a selected row stays selected when it scrolls out of the window and back, and through a sort. Arrow keys move between cells (one tab stop).
