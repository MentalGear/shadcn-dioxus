A sortable task list of 200 rows, each with a grip, a checkbox and a label. The list fills the demo frame's width. Drag a grip onto another row, or press Space on it, move with Up and Down, and press Space to drop (Escape cancels); the drop line is in the accent colour. Reverse and Shuffle reorder in one click. The list passes `item_key`, so a task's checkbox, focus and measured height follow it to its new place; without `item_key` a row is its slot, and the checked box and focus would stay at the same position while a different task appeared there (see Identity in the docs above).
