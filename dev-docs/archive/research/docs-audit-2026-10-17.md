## 2. Docs buttons vs ui.shadcn.com
Method: curl of https://ui.shadcn.com/docs/components/base/button (UA shadcn-dioxus-research) plus its 4 CSS chunks, rebuilt the real demo markup locally (`scratch-docsaudit/replica/index.html`) and read computed styles in Chromium; ours measured live at /component/button/ via `window.__dxApplyMode`.
Facts: the live docs page uses `styleName="base-nova"` for the button page (`<ComponentPreview styleName="base-nova" name="button-demo"/>`; attachment/avatar-ish chat-kit pages use `base-rhea`). Its theme: default neutral tokens `--primary #000`, `--primary-foreground #fafafa`, `--secondary #f5f5f5`, `--secondary-foreground #171717`, `--destructive #e40014`, `--border #e5e5e5`, `--radius .625rem`, `--foreground #000`.
Geometry (radius 10px, h 32/28/24/36, px 10, 14px/500, border 1px, no shadow) is IDENTICAL in all sizes. Differences, light mode:
| item | shadcn base-nova | ours | cause |
|---|---|---|---|
| Destructive | bg destructive/10 (tint), text #e40014 | solid #dc2626 fill, white text | deliberate, `P/button/style.css:236-255` (backlog row 134: tint fails 4.5:1) |
| Primary text | #fafafa | #fff | `--dx-primary-foreground` falls back to `--primary-color` (`assets/dx-components-theme.css:205`) |
| Secondary text | #171717 | #000 | fallback `--secondary-color-1` (`dx-components-theme.css:207,114`) |
| Outline/Ghost text | #000 (--foreground) | #111 | `--dx-foreground` falls back to `--secondary-color-4` #111 (`:192,117`) |
| Link text | #000 | oklch(0) clamped, same | none |
| Destructive hue | #e40014 | #dc2626 | `--dx-destructive` fallback (`:229`) |
Dark mode: primary text #171717 vs ours #000; foreground #fafafa vs ours #d4d4d4 (outline/ghost/link text visibly dimmer); destructive solid 60% fill vs shadcn tint.
Cause: the docs site is not given shadcn's `--foreground/--primary-foreground/--secondary-foreground/--destructive` tokens, so the theme's Dioxus-legacy fallbacks (`--secondary-color-*`, `--primary-color`) win; backgrounds/borders/sizes already match.
Frame (what the owner likely sees as "different bg"):
| | shadcn | ours |
|---|---|---|
| frame | `rounded-2xl border`, `h-72 p-10` (288px/40px), NO bg (page bg) | `.dx-component-preview-frame` (`assets/main.css:1345-1360`): radius 8px, padding 32px, min-h 176px, `background-color: --dx-card` (#171717 in dark vs page #0a0a0a) plus a 16px DOTTED radial-gradient grid |

| section layout | one section per variant (Default, Outline, Secondary, Ghost, Destructive, Link, Size, Icon, ...) | one demo + "Variants" |
Note also: our default variant is named `Primary`/`data-style="primary"` (shadcn: `default`).
Proposal: (a) S, set shadcn tokens in the docs site root (`preview/assets/main.css` or theme default block) `--foreground:#000; --primary-foreground:#fafafa; --secondary-foreground:#171717; --destructive:#e40014` and dark equivalents, or change the fallbacks in `dx-components-theme.css:192-229` (affects all components, run all gates + theme-contrast specs; the destructive text/contrast gates may fail). (b) S, frame: drop the dot grid and card bg, `border-radius:1rem`, `padding:2.5rem`, `min-height:18rem` in `main.css:1345` (touches every component page, review screenshots). (c) S, make the button main demo shadcn's (outline Button + icon button) and move the 6 variants to a variant. (d) decide on destructive tint (row 134 trade-off): needs an owner call.
