# Row 162: Self-host the docs site's fonts (no runtime requests to Google) and give the library --dx-font-sans /…

## Item

Self-host the docs site's fonts (no runtime requests to Google) and give the library `--dx-font-sans` / `--dx-font-mono` tokens, so an app chooses its own fonts

## Status / trigger

**LANDED 2026-10-19 (lane fonts)**

## Size

S-M

## Detail

**Facts (measured 2026-10-05).** Ours: 2 families, both variable, loaded from Google Fonts at runtime: Geist (wght 100-900) and Geist Mono (400/500/700). The Latin-subset woff2 files are Geist 29.4 KB + Geist Mono 23.1 KB = ~52.5 KB, plus an 8.5 KB Google CSS file and connections to 2 Google hosts (`fonts.googleapis.com`, `fonts.gstatic.com`). They are preloaded with `display=optional` since this round (the font CLS fix: hard-load CLS 0.117 -> 0.000 on `/component/form/`); the links live in `preview/src/main.rs` (~`:2044-2073`) and `preview/src/eager_head.rs` (~`:259`), the `font-family` rules in `preview/assets/main.css` (`body` at `:109`; `Geist Mono` on 14 lines). **The library sets no font of its own, on purpose: only the docs site's `main.css` does, and components inherit, which is correct.** **Two exceptions found while writing this row** (read from the CSS, not yet confirmed by a computed-style check): (1) `dialog`, `alert_dialog`, `sheet` and `drawer` (`style.css` ~`:154-182` each) and `calendar`'s root (`:21`) hard-code a system sans stack, so they do NOT inherit the app's font and would stay in the system face when the page is Geist (13 other component declarations are `font-family: inherit`, which is right); they must move to `inherit` or `var(--dx-font-sans)` in this row, or the new token never reaches dialogs, sheets, drawers and the calendar; (2) `preview/src/main.rs:2840-2849` and `drag_and_drop_list`'s demo set `monospace` stacks inline: fold them into `--dx-font-mono`. **shadcn, for reference:** the font is a per-project choice. `DEFAULT_CONFIG` is style `nova` + font `inter`; the Nova preset (`radix-nova`) uses Geist, Vega/Mira/Luma use Inter, Maia uses Figtree, Lyra uses JetBrains Mono. shadcn apps load fonts through `next/font`, which downloads them at build time and SELF-HOSTS them, so there are no runtime requests to Google. **Options for the docs site:** (a) self-host Geist + Geist Mono (~52.5 KB; matches the Nova look); (b) self-host Geist only and use the system monospace stack for code (~29 KB, one file); (c) the system font stack only (0 KB; looks different on every OS). **Recommendation: (b)**, plus library tokens `--dx-font-sans` and `--dx-font-mono` defined in `preview/assets/dx-components-theme.css` with system-stack defaults, so an app picks its fonts by overriding two variables; the docs site overrides `--dx-font-sans` with Geist in `main.css`. Components read the tokens (or inherit), never a literal family. **Mechanics:** the woff2 under `preview/assets/` through `asset!` (hashed, base-path-safe), `@font-face` with `font-display: optional` kept (the CLS fix), a preload of the self-hosted Latin file with `crossorigin`, and no Google `preconnect` or stylesheet link left in `main.rs` or `eager_head.rs`. Latin subset only: characters outside it fall back to the system stack (Google's CSS also served latin-ext on demand; adding it costs bytes not measured here). Geist is SIL OFL: ship the licence text beside the files. **The gate, by construction:** widen `scripts/check-demo-remote-assets.sh` from images to fonts, stylesheets and scripts (a remote `@font-face` `url()`, a `<link rel="stylesheet">` or `document::Link` with a remote `href`, a `<script src>` with a remote URL), so nothing remote can return after this row; the script's header says fonts are "Not flagged" today and must be reworded, and the first run will list whatever else is remote (allowlist only with a stated reason). **Done when:** the SSG build makes zero requests to Google hosts (a Playwright network assertion on the home page and one component page), CLS stays 0 on `/component/form/`, the gate fails on a seeded remote font, and the five hard-coded stacks are gone. **Owner:** pick (a), (b) or (c); the recommendation is (b). **Owner decision 2026-10-05 (later the same day): option (a), self-host Geist + Geist Mono (~52.5 KB, about 23 KB of it the mono face); it stays on the next-session list (step 4).** The mechanics above stand, now for both files: `--dx-font-sans` and `--dx-font-mono` in `dx-components-theme.css` with system-stack defaults (a library user picks fonts by overriding two variables), the docs site overriding both with Geist and Geist Mono in `main.css`, `@font-face` with `font-display: optional` and a `crossorigin` preload of the two latin files, no Google `preconnect` or stylesheet left (the links are still in `preview/src/main.rs` at ~`:2060-2073`), the OFL licence text beside the files, and the widened `check-demo-remote-assets.sh`. The inline `monospace` stacks (`preview/src/main.rs:2840-2849` and `:2967`, and the `drag_and_drop_list` main demo) fold into `--dx-font-mono`. **Landed 2026-10-05 (round 3), the first of the two exceptions found while writing this row:** `dialog`, `alert_dialog`, `sheet`, `drawer` and `calendar` no longer hard-code a system sans stack (they inherit, so the app font reaches overlays and the calendar), and `scripts/check-component-fonts.sh` (in `run-gates.sh`) makes the class inexpressible: a component `style.css` `font-family` may only be `inherit` or `var(--dx-font-<name>)` (an `inherit` fallback allowed), `font` only `font: inherit`, and `@font-face` is flagged. So "the five hard-coded stacks are gone" in this row's done-when is already true, and 162 no longer edits those five sheets. Related and landed: the font CLS fix (`display=optional` plus latin preloads: `/component/form/` 0.117 -> 0.000, `/component/carousel/` 0.048 -> 0). Facts and numbers: [round-3 note](../../research/round3-2026-10-05.md), section 6.

**Update 2026-10-19 (lane fonts): LANDED.** Geist + Geist Mono (Latin subset, variable woff2, 29.4 + 23.1 KB, fetched from fonts.gstatic.com with a generic UA) now live in `preview/assets/fonts/` with the OFL text beside them. `GlobalHead` writes the two `@font-face` rules (`font-display: optional`, latin `unicode-range`) and the two `crossorigin` preloads from the SAME `asset!` constants, because `asset!` hashes the file names and does not rewrite a stylesheet `url()` (so the rules cannot sit in `main.css`). Google preconnect/stylesheet links are gone from `main.rs`; `eager_head.rs` only lost a test fixture URL (it never linked fonts), `index.html` had none. Tokens: `--dx-font-sans` / `--dx-font-mono` in `dx-components-theme.css` inside a zero-specificity `:where(:root)` (system-stack defaults, any app override wins whatever the sheet order); `main.css` overrides both with Geist / Geist Mono and its 14 literal mono stacks + body now read the tokens. Inline `monospace` stacks in `main.rs` and the drag_and_drop_list main demo read `var(--dx-font-mono)`. Gates: `check-demo-remote-assets.sh` now also flags a remote font host, remote `@import` and remote `document::Stylesheet` (seeded self-test fails), `check-css-delivery.sh` holds preload + `font-display:optional` + no remote URL in GlobalHead. Spec: `playwright/fonts-self-hosted.spec.ts`. Left: `hero.css` still names `"Geist Mono"` literally (not in this lane's file set; works, should read the token).
