**Update 2026-10-19 (markdown):** the `markdown` registry component landed (`preview/src/components/markdown/`), built exactly to the 2026-10-15 owner decisions. Design: pulldown-cmark `=0.13.4`, default features off, only `ENABLE_TABLES | ENABLE_STRIKETHROUGH | ENABLE_TASKLISTS`; the event stream is folded into a closed `Node`/`Kind` tree with no raw-HTML variant (raw HTML, inline HTML and math become text nodes), and a link or image target exists in the tree only as a `SafeHref`, whose single constructor `safe_href` allows http, https, mailto, tel and relative targets and rejects any target containing whitespace, a control character or a backslash (so `java<TAB>script:` and `/\evil` die with `javascript:`/`data:`). External links get `target="_blank" rel="noopener noreferrer"`. Images are off by default (`allow_images` opts in, lazily, `no-referrer`, never for a script source; alt text stays). Code blocks are a plain `<pre><code class="language-x">` (language only if a short identifier) with a `highlight: Callback<CodeBlock, Element>` slot; no highlighter ships. `heal_markdown` (streaming) heals only the last paragraph (unclosed code span, `**`/`*`/`_`/`~~`, partial `[label](url`, a partially typed closing fence) and is total and idempotent on every prefix of a nasty document; bare-URL autolinks are the component's own pass over text nodes. No math. Gates: new `scripts/check-markdown-parser.sh` (the parser allowlist: component.json crates exactly primitives + pulldown-cmark with no features, the exact pin and `default-features = false` in `preview/Cargo.toml`, the lock's pulldown-cmark deps limited to bitflags/memchr/unicase/pulldown-cmark-escape, `pulldown_cmark` named only inside the component, no html renderer, `Options` flags allowlisted, no `dangerous_inner_html`), registered in `scripts/run-gates.sh`; the versions-match-the-lock half was already `check-cargo-dep-versions.sh` (its `PARSER_ALLOW` entry for `markdown` and the `=` rule now have a component to bind to). Docs `docs.md`, six demos (main, streaming with `MessageScroller` and a heal switch, links, images, code_slot, xss), `playwright/markdown.spec.ts` (structure, link policy incl. a real popup with no opener, images off then opt-in, XSS inert, highlight slot, heal on/off over a streaming reply, axe light and dark) and the component's `cargo test` module. Same lane: row 148 (Chat sidebar category).
