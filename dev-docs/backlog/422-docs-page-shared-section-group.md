# Row 422: Component pages: group the shared sections under one header

## Item

The owner's ask (2026-10-25, backlog thread): on every component page, group the sections that every component has
under one header, for example Usage Notes (expanded by default), Props Reference, Installation and Component Structure.
Put the component-specific accordion sections under another header.

## Status / trigger

BACKLOG, owner decision before building. The owner asked for the headers and an outline before work starts, so the
first deliverable is a proposal (header names, which sections go where, default open state, one example page) for the
owner to approve. Docs stage of the adopted order: after row 394 (the "Coming from shadcn / Radix / TanStack" table
also adds a shared section on every page, so both decide the same layout once).

## Size

M

## Detail

The page is generated by `preview/build.rs` from each component's `docs.md`, plus the generated props table
(`preview/props_scan.rs`) and the Installation section. `check-docs-own-components.sh` requires the docs to use the
library's own Accordion. `check-docs-no-demo-list.sh` already keeps demo lists out of `docs.md`. The grouping is decided
once in the generator, not per `docs.md`.
