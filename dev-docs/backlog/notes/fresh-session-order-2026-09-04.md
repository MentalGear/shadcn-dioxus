## Fresh-session order (2026-09-04)

The table below is ranked by take-order already; this block is a **recommendation for what a fresh session should pick up first**, layered on top of it — easy to reverse, not a renumbering of the rows. Rationale: fix what's broken before building more, cheap infrastructure before expensive components, and keep CI-gated items visibly separate from everything else since they aren't sequenced at all (they wait on the user lifting the CI freeze).

**Environment note (2026-09-04):** this sandbox got a working Playwright container for the first time this session — `dx` 0.7.9 and the wasm32 target installed, chromium/firefox/webkit browsers all installed, `dx build --web --release` succeeds. Three `dx`-managed tool downloads had to be placed by hand because `dx`'s HTTP client does not trust the agent proxy's CA (`invalid peer certificate: UnknownIssuer`): esbuild 0.27.3 and binaryen/wasm-opt into `~/.local/share/.dx/tools/`, and wasm-bindgen compiled from source. A fresh session hitting the same proxy should expect the identical failure and know the workaround rather than rediscovering it. A firefox+webkit calibration run (row 4) was started in this same sandbox and was **deliberately stopped partway** (178/1094, 14 failures recorded in firefox) as a scope decision — it is user-gated group-6 work (item 5 below) and was blocking the queue. Its outcome is genuinely incomplete, not merely unreported: a fresh session resuming calibration should rerun it cleanly rather than try to pick up where it left off.

**Environment note (2026-09-18):** a fresh container again had no `dx`. GitHub over HTTPS is blocked by this environment's egress policy (403 on `api.github.com` and on release downloads) but `git fetch` from github.com works — forks and upstream `refs/pull/N/head` included — and crates.io works, so `cargo install dioxus-cli --version 0.7.9 --locked` (~20 min on 4 cores) is the route. `dx` then self-compiles wasm-bindgen from source when its GitHub download fails (144 s, into `~/.local/share/.dx/tools/wasm-bindgen-0.2.121/`), but its own reqwest client (webpki roots) rejects the proxy CA even for `NO_PROXY` hosts, so the other two tools were placed by hand at the paths `dx` checks first: esbuild 0.27.3 from the npm tgz (curl trusts the CA) at `~/.local/share/.dx/tools/esbuild-0.27.3/esbuild`, and `wasm-opt` at `~/.local/share/.dx/tools/binaryen-129/bin/wasm-opt` as a wrapper over the npm `binaryen@129.0.0` JS/wasm build (Ubuntu's apt `binaryen` is version 108 — it accepts every flag `dx` passes but predates the sign-ext/multivalue defaults rustc 1.94 emits, so it was not used). Parallel lanes ran in git worktrees sharing one cargo build directory (`~/.cargo/config.toml` `build.target-dir`), which reuses compiled dependencies across worktrees; cargo serialises on its lock, so "Blocking waiting for file lock" is expected, not a hang.

**New lints and tools landed this session, all wired to rows 31b/32:** two mechanical-check scripts joined `scripts/check-preview-composition.sh` and `scripts/check-cfg-axis.sh` — `scripts/check-dx-class-prefix.sh` (every themed component's shipped classes must be namespaced `dx-<component>[-...]`, the collision-safety property `#[css_module]` hashing used to provide, now that row 32 has dropped it) and `scripts/check-css-literals.sh` (a themed stylesheet may not hard-code a value that exactly matches a row-31a design token, enforcing row 31b's migration against drift). Both should run alongside the existing gates before any CSS-touching change lands. Two Playwright files are TOOLS rather than oracles, not run as part of the normal suite: `playwright/dx-class-migration.spec.ts` (generic per-component delivery + unhashed-class assertions — this is the one that caught `sidebar`'s stylesheet not reaching its iframe-embedded demo, and now also the calendar/date_picker one row 51 fixed) and `playwright/computed-style-snapshot.spec.ts` (skipped unless `DX_SNAPSHOT` is set; captures computed styles across every themed page so a literal→token migration can be proven value-preserving by diff rather than by eye).
