## The amendment (DESIGN): admission is derived from the placement table, per effect

Round 3's two grounds (a detected structural effect, or a late-arm witness) admitted a whole variant on one ground, so riders got in (`pan`'s next-frame `setVar`/`scrollBy`, `after(...)` loops, `otpFilter`'s `setValue`), `hotkey{prevent:false}` was admitted at its sample parameters although it is a page-side `listen` that the table places in R, a detected `prevent` proves capability not need, the witness's row and assertion were chosen by the author, and the order condition (2.2, 1(b)) had no ground at all (`reconcile` was filed under `sameFrameWrite`, but an unshown `[popover]` is `display:none`, so a late open paints nothing wrong).

**Amended admission.**
1. **The unit is the effect, at each Rust construction site's parameters.** The generated effect set is computed per parameterisation; a construction whose set is empty does not compile (split the type or a `const` check), and that call site uses `listen`.
2. **One ground: the counterfactual witness.** For each effect, the adapter's witness mode moves only that effect to its next-best placement under the table: `prevent`/`stop`/`dataTransfer` dropped (what R does to them); an element-target default-action decision on an event Dioxus delivers installed in the bubble phase at the element (the rsx placement); writes, `focus` and `capture` delayed by R's modelled latency (provisionally 3 frames, set by the step-0 desktop distribution, never less than the row's deadline); order-ground decisions have the fact reordered after the next vdom event (desktop-cadence harness). Memory and `send` stay synchronous.
3. **A red counts only from a library commit-point probe** (`wrongPaint(predicate)` read at the end of the ResizeObserver phase, `defaultAction(occurred)`, `focusAtNextInput` driven at key-repeat rate, `outcomeOrder`), never from a latency number or a spec-authored assertion. The next-frame row's witness remains the owner's measurement verdict (row 443), which is the same counterfactual on hardware; `verdict.json` carries a reason and only `lag` or `order` admits.
4. **Structural detection is the inventory, not a ground:** a per-kind `Decision<E>` type, behaviour modules compiled without the DOM library, and an adapter that refuses an undeclared effect guarantee the code's effects are a subset of the declared ones; the witness proves each declared one is needed.
5. **Witnesses run, they are not records:** each is an expected-failure test (`test.fail()` plus a typed probe error) in `test:changed` and in the deploy suite; witness files and `verdict.json` must exist at the merge base.

Subsumes: the two-ground split, the next-frame special case, "`settle`/`scrollStep`/`roving`/`place` only on a red witness", the order condition's page-side owners, riders, `hotkey{prevent:false}`, and the unchecked "capture phase" reason (its counterfactual is the bubble install). ## Order: one contract instead of three mechanisms (DETAIL, major; folded with the amendment)

An absolute set commutes only with events that do not write the same slot, and the slots the user also writes are scroll position, open state, focus and value (W8's `scroll(end)`, T12 close-on-scroll after a reopen, Escape after a light dismiss, S4/V6 setters during a wheel). Facts from different sessions are processed in owning-scope height order (`dioxus-core-0.7.9/src/scheduler.rs:106-110, 149-163, 247-258`), not arrival order, so "both sides on the bridge" is not ordered.
- (a) Facts carry the epoch of the slot they observed, read on the page at emission.
- (b) A Rust write to a page-written slot goes through that slot's page owner (the reconciler or its Rust transaction for open state, `openFocus`/`roving` for focus, the scroller's behaviour or a fenced setter row for scroll position), carrying the epoch it was decided from; the owner drops a write older than the slot's last page transition.
- (c) "Commutative" means an absolute set on a slot only Rust writes.
- Facts a decision combines share one session (or one inbound pump with a page-minted sequence dispatched by one root task); the timing contract gains the scheduler row; the desktop-cadence harness reorders across sessions.
This subsumes the reconciler's generation, `stickToEnd`'s epoch, condition 3, T12, Escape, S4 and V6.
