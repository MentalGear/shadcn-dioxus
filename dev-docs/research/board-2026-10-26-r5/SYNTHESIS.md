## Amendment 1 (DESIGN, additive): admission has a second, closed ground

The counterfactual witness cannot see commit points outside the page or outside the container's engine: browser-chrome defaults (O1 cancels F6, V22 cancels Ctrl/Cmd+B, which open the address bar and bookmarks sidebar in Firefox; L6's only web caller is a plain `div` dialog), and engine rules Chromium does not enforce (WebKit requires a clipboard write inside the user gesture; a 3-frame-late call still works in Chromium, so the witness would demote the effect and ship it broken on Safari and WKWebView).

Admission per effect is: **the counterfactual witness red**, or, only where no probe in the available engines can observe the commit point, **a cited platform rule**: one reasoned row per effect with a W citation, the engine, a `desktop-pass`/manual check line, and an owner-approved grant row at the merge base. Where Playwright WebKit can observe it, the witness must run there before an effect is demoted. Witnesses that serve other engines (`stickToEnd` against `overflow-anchor`, the drag-source half) run under fallback emulation.

## Amendment 2 (DESIGN, additive, borderline): rsx decisions read page transitions through the vdom's ordered path

Dioxus events carry no epoch: the interpreter serializes a fixed set of fields per event, without dataset or timestamp (`dioxus-interpreter-js-0.7.9/src/ts/serialize.ts:279-313`). So an rsx handler deciding on a page-written slot only has Rust's lagging copy, and on desktop the epoch fence either drops the user's input or lets web and desktop end in different states (a light dismiss followed by the trigger's `onclick` in the same gesture, already documented at `popover_sync.rs:200-225`; "Escape, then Enter").

A page transition that an rsx decision reads reaches Rust on the vdom's own ordered path: the hidden transition port (today's remedy (iii)) becomes a first-class carrier. Epochs stay for bridge facts and Rust-to-page writes. One inbound pump is the only page-to-Rust bridge path, so "facts a decision combines share one session" holds by construction (the shipped Accordion uses one session per panel).
