# Agent rules: procedure files, read on demand

CLAUDE.md names the trigger; the file here carries the rule text. Read the file when its trigger fires, before acting.
- delegation-and-models: delegating, briefing a lane agent, choosing a model
- gates-before-commit: committing, calling a change finished, adding a gate
- build-and-fast-loop: cargo/dx/SSG builds, dx serve, Playwright
- commits: writing a commit message
- merge-and-install: merging lane branches, adding or changing a component
- code-rules: comments, test titles, demo text, JS interop, a repeated problem
- session-and-backlog: a fresh container without dx, editing a backlog row
