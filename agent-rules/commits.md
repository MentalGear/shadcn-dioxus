# Commits

Read this when you are about to write a commit message.

- Run the gates first: [`gates-before-commit.md`](./gates-before-commit.md).
- Use the `commit-guide` skill when it is available; when it is not loaded (e.g. this remote environment), say so once
  and follow the convention already used in this repo: Conventional Commits `type(scope): subject`, a body that
  explains the why and the evidence, the attribution trailers. Deviate only for a valid concern, and state it.
